# SatViz
A project intended to push the lines of satellite-intelligence collection &amp; the aggregation of said data. This project will attempt to gather and project positional data, and, potentially communications. Establishing a clean and simple interface, this project is a work-in-progress and will extend as long as programming technique and legality allow.
